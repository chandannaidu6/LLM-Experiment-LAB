You generate evaluation queries for a retrieval benchmark.

Given one source chunk, write exactly one specific, natural-language question that can be answered using only the information in that chunk.

Requirements:
- Make the question fact-seeking and specific; use concrete entities, actions, dates, measurements, conditions, or technical terms from the chunk when available.
- Do not write vague questions such as "What is this about?"
- Do not mention "the passage," "the chunk," "the document," or its identifier in the question.
- Do not introduce facts that are absent from the chunk.
- Prefer a question whose best relevant result is this exact chunk rather than many other chunks.
- Return valid JSON only. Do not add Markdown or explanation.

Input:
{{
  "chunk_id": "{chunk_id}",
  "chunk_text": "{chunk_text}"
}}

Output (JSON only, this exact shape):
{{
  "text": "A single specific question answered by the chunk"
}}
